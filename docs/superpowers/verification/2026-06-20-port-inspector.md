## 验证清单

### 1. 自动扫描 + 状态摘要
- [ ] 进入 `/ports` 页面，**1 秒内**应自动出现「系统所有 LISTENING 端口」
- [ ] 顶部状态条：「N 监听中 · 0 冲突 · 刚刚」
- [ ] 表格行有数据，每行有 🌍「打开」按钮
- [ ] 「结束」按钮只在有 PID 的行出现
- [ ] 状态点（●）显示绿色 = 实时；点击 ⏸ 后变灰

### 2. 2 秒自动刷新
- [ ] 启动测试服务：`python3 -m http.server 12345`
- [ ] 进入 `/ports` 页面，**2 秒内**应看到 12345 端口「新增」（绿色高亮）
- [ ] 5 秒后绿色淡出
- [ ] **关闭**测试服务（Ctrl+C），2 秒内该端口行变红（diff=gone）+ 文字 line-through
- [ ] 5 秒后该行从表格消失

### 3. 浏览器打开
- [ ] 启动测试服务占用 12345：`python3 -m http.server 12345`
- [ ] 点击表格的 🌍「打开」按钮
- [ ] 系统默认浏览器应打开 `http://localhost:12345`

### 4. 「我的服务」过滤
- [ ] 在「服务」页配置一个 service.port = 3306
- [ ] 启动外部 mysqld 占用 3306（可选）
- [ ] 顶部「★ 我的服务 (N)」标签
- [ ] 点击「我的服务」：只显示我的服务声明的端口
- [ ] 如果 3306 被外部占用：「关联服务」列显示「⚠ mysql」红字
- [ ] 顶部「冲突」数字 ≥ 1（红色）

### 5. 标签页可见性暂停
- [ ] 切到其他标签页（如浏览器、其他 Tauri 页面）
- [ ] 10 秒后切回
- [ ] 顶部状态条显示「已暂停（标签页隐藏）」→ 立即变回「实时」并补刷一次

### 6. 手动暂停
- [ ] 点工具栏的 ⏸ 按钮
- [ ] 状态条显示「已暂停（手动）」
- [ ] 2 秒后表格不变（停止扫描）
- [ ] 再点 ⏸ 按钮恢复
- [ ] 验证「刷新」按钮仍然有效（不依赖轮询）

### 7. 底部状态条
- [ ] 显示「共 N 个端口 · X 空闲 · Y 监听中 · Z 冲突」
- [ ] 显示「扫描耗时 XXXms」（应该 < 200ms；如 > 2000ms 触发降频）
- [ ] 显示「引擎 IP Helper API」+ 实时/已暂停指示

### 8. 快速过滤
- [ ] 依次点击「全部 / 我的服务 / 仅 LISTENING / 仅冲突」
- [ ] 表格行数变化符合预期
- [ ] 当前激活的标签为蓝色

### 9. 杀进程 + 自动重扫
- [ ] 在表格中找到占用行
- [ ] 点「结束」按钮
- [ ] Toast「已结束 PID xxx」
- [ ] 2 秒内该行变红（diff=gone），5 秒后消失

### 10. 性能验证
- [ ] 系统上 > 50 个 LISTENING 端口时，扫描耗时 < 200ms
- [ ] 表格重渲染无明显卡顿
